# Rustvers

Лёгкое хранилище заметок в духе Obsidian для Linux: папка с `.md` и `.html` файлами, граф связей между ними, просмотр и правка заметок.

## Запуск

Только Linux. Нужны Rust, WebKitGTK (`webkit2gtk-4.1`) и Wayland-композитор с EGL — на Arch/CachyOS: `pacman -S webkit2gtk-4.1`.

```bash
cargo run -- demo-vault          # открыть конкретную папку
cargo run                        # последнее открытое хранилище или экран выбора
cargo build --release            # ~5 МБ бинарь в target/release/rustvers
cargo test --lib                 # тесты ядра
```

## Возможности

- **Граф связей**: нативная отрисовка на частоте экрана, силовая раскладка (Barnes–Hut), масштаб колесом, перетаскивание узлов и холста, подсветка соседей при наведении, поиск, «призрачные» узлы для несуществующих заметок.
- **Markdown** (pulldown-cmark): `[[ссылки]]`, `[[Заметка#Заголовок|подпись]]`, `![[картинка.png]]`, таблицы, сноски, задачи, GFM-алерты, YAML-frontmatter.
- **HTML-заметки**: полноценные страницы со своими стилями и скриптами. `[[ссылки]]` в тексте и `<a href="другая.md">` тоже попадают в граф. HTML-фрагмент без `<html>` оформляется как обычная заметка.
- Обратные и исходящие ссылки, дерево файлов, история (Alt+←/→).
- **Правка заметок** (`Ctrl+E`): редактор исходника Markdown/HTML с автосохранением, продолжением списков по Enter и подсказками имён при вводе `[[`. Запись атомарная; если файл изменили снаружи, сохранение не затрёт чужую версию.
- **Новые заметки** (`Ctrl+N` или «+»): `Имя`, `папка/Имя` или `Имя.html`. Клик по несуществующей ссылке или «призрачному» узлу графа создаёт заметку.

Горячие клавиши: `Ctrl+K` — поиск, `Ctrl+G` — граф/заметка, `Ctrl+E` — правка, `Ctrl+N` — новая заметка, `Ctrl+S` — сохранить сразу, `Ctrl+O` — открыть папку, `Ctrl+R` — пересканировать, `Ctrl+Shift+F` — счётчик кадров графа.

## Устройство

```
src/core/      чистая логика, без GUI (можно переиспользовать в CLI и т.п.)
  vault.rs       индекс файлов, разрешение ссылок как в Obsidian
  links.rs       извлечение ссылок из Markdown/HTML, [[wiki]]-парсер
  render.rs      заметка → самостоятельный HTML-документ
  graph.rs       узлы и рёбра
  layout.rs      силовая раскладка (Barnes–Hut)
  paths.rs       пути, slug-и, экранирование
src/app/       оболочка Tauri
  commands.rs    хранилище и заметки: открыть, пересканировать, читать, сохранить, создать
  state.rs       сессия: граф, кэш ссылок, атомарная запись
  protocol.rs    схема note:// — отдаёт заметки и вложения
  graph_cmd.rs   команды нативного графа
  native/        Linux/Wayland: граф в своей wl_subsurface на частоте экрана
assets/        стили заметок и мост iframe ↔ приложение
ui/            интерфейс: ванильный JS без сборщика (app, editor, tree, native-graph)
```

Заметка открывается в `<iframe sandbox="allow-scripts">` по адресу `note://localhost/<путь>`. Поэтому относительные картинки работают сами, а скрипты HTML-заметок изолированы от приложения. Схема `note://` отдаёт только файлы, которые есть в индексе хранилища; скрытые файлы и пути за пределами корня недоступны.

### Граф

WebKitGTK и GTK3 на части систем рисуют не чаще 60 раз в секунду (например, если экран подключён к NVIDIA: `drmWaitVBlank` недоступен). Поэтому граф рисуется нативно: Rust создаёт `wl_subsurface` поверх области графа и рисует её через OpenGL ES (femtovg) в отдельном потоке, а темп задаёт композитор — частота экрана. Мышь над этой областью перехватывается в GTK до WebKit. HTML не может лежать поверх графа, поэтому его панели вынесены в панель инструментов.
